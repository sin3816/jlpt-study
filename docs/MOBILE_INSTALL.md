# 갤럭시 S24 Ultra 설치 가이드 (모바일 웹앱 + PC 동기화)

폰 버전은 **PWA(설치형 웹앱)** 입니다. 웹 주소를 한 번 열고 "앱 설치"를 누르면 Chrome이 진짜 안드로이드 앱(WebAPK)으로 설치해 줍니다.

- 홈 화면·앱스 화면에 아이콘이 생기고, 주소창 없이 전체 화면으로 열립니다.
- 설정 → 애플리케이션 목록에도 나옵니다.
- 처음 한 번 열면 앱 파일이 저장되어 **인터넷 없이도 실행**됩니다.
- APK 파일을 따로 받을 필요가 없고, "출처를 알 수 없는 앱" 허용이나 Auto Blocker 해제도 필요 없습니다.

전체 순서는 다음과 같습니다. 처음 한 번만 PC에서 10~15분 정도 걸립니다.

1. **PC:** 웹앱을 GitHub Pages에 올리기 (무료 웹 주소 얻기)
2. **폰:** 그 주소를 열어 앱 설치
3. **PC·폰:** 같은 GitHub 토큰을 입력해 동기화 연결

---

## 1. 웹앱 올리기 (PC, 처음 한 번)

### 1-1. GitHub 저장소 만들기
1. https://github.com 에 가입하거나 로그인합니다. 개인 계정을 권장합니다.
2. 오른쪽 위 **+** → **New repository**
   - Repository name: `jlpt-study`
   - **Public** 선택. 무료 GitHub Pages는 공개 저장소에서만 됩니다.
     공개되는 것은 앱 코드와 문제뿐이고, 학습 기록과 토큰은 저장소에 들어가지 않습니다.
   - README·.gitignore 추가는 **체크하지 않습니다**.
   - **Create repository**

### 1-2. 코드 올리기
명령 프롬프트(또는 IntelliJ 터미널)에서 실행합니다. `<아이디>`는 내 GitHub 아이디로 바꾸세요.
```bat
cd C:\dev\IdeaProjects\jlpt-study
git branch -M main
git remote add origin https://github.com/<아이디>/jlpt-study.git
git push -u origin main
```
로그인 창이 뜨면 GitHub 계정으로 로그인합니다. 회사 Git 계정과 헷갈리지 않게 주의하세요.

### 1-3. GitHub Pages 켜기
1. 저장소 **Settings** → 왼쪽 **Pages**
2. **Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
3. 저장소 **Actions** 탭 → **웹앱 배포 (GitHub Pages)** → **Run workflow**
4. 1~2분 뒤 초록색 체크가 뜨면 완료입니다. 앱 주소는 아래와 같습니다.
   **`https://<아이디>.github.io/jlpt-study/`**

이후에는 PC에서 `git push`만 하면 검사(문제 데이터·로직 테스트)를 거쳐 자동으로 다시 배포됩니다.

## 2. S24 Ultra에 설치

1. 앱 주소를 폰으로 보냅니다. 예: 카카오톡 "나에게 보내기"
2. 폰에서 **Chrome**으로 주소를 엽니다. 카톡 안의 브라우저가 열리면 오른쪽 위 메뉴 → "다른 브라우저로 열기" → Chrome을 고릅니다.
3. Chrome 오른쪽 위 **⋮** → **앱 설치**를 누릅니다. 메뉴에 따라 **홈 화면에 추가 → 설치**로 보일 수 있습니다. 화면 아래에 설치 안내가 뜨면 그걸 눌러도 됩니다.
4. 홈 화면 또는 앱스 화면의 **JLPT 스터디** 아이콘으로 실행합니다.

> 삼성 인터넷으로도 설치됩니다: 메뉴(≡) → **현재 페이지 추가** → **홈 화면**. 동작은 같고, Chrome을 권장합니다.

### 일본어 음성 켜기 (청해·발음 듣기)
앱은 휴대폰의 TTS 엔진으로 일본어를 읽습니다.
1. 휴대폰 **설정** 검색창에서 **TTS**(텍스트 음성 변환)를 검색합니다.
2. **기본 엔진**을 **Google 음성 인식 및 합성**으로 바꿉니다. 삼성 TTS에 일본어가 없을 수 있기 때문입니다.
3. 엔진 옆 ⚙ → **음성 데이터 설치** → **일본어**를 내려받습니다.
4. 앱을 완전히 닫았다가 다시 엽니다. 앱의 **더보기 → 설정 → 음성 테스트**로 확인하세요.

음성이 없어도 청해 문제는 스크립트를 보여 주므로 풀 수 있습니다.

### 업데이트
PC에서 push해 새 버전이 배포되면, 폰 앱을 **두 번 열 때** 반영됩니다. 첫 실행 때 새 파일을 받고, 다음 실행부터 적용됩니다.

## 3. PC ↔ 폰 동기화 연결

GitHub **비공개 Gist** 하나에 학습 기록을 저장하고 기기끼리 자동으로 합칩니다. 원리는 [SYNC_DESIGN.md](SYNC_DESIGN.md)를 참고하세요.

### 3-1. 토큰 만들기 (Gists 권한만)
1. GitHub 오른쪽 위 프로필 사진 → **Settings** → 맨 아래 **Developer settings**
2. **Personal access tokens → Fine-grained tokens → Generate new token**
   - Token name: `jlpt-sync`
   - Expiration: 1년(또는 원하는 기간)
   - Repository access: **Public repositories** (저장소 권한은 필요 없습니다)
   - Permissions: **Account permissions**(계정 권한)에서 **Gists**를 **Read and write**로 설정합니다. 다른 권한은 주지 않습니다.
3. **Generate token**을 누르고 `github_pat_…`로 시작하는 토큰을 복사합니다. 이 화면을 벗어나면 다시 볼 수 없습니다.

### 3-2. PC 앱 연결
JLPT 스터디(Windows **1.1.0 이상**) → **설정** → **PC ↔ 폰 동기화** → 토큰 붙여넣기 → **연결**
→ "연결했어요. 이 기기의 기록을 올렸습니다"

### 3-3. 폰 앱 연결
1. 토큰을 폰으로 보냅니다(예: 카톡 나에게 보내기). 붙여넣은 뒤에는 **메시지를 삭제**하세요.
2. 폰 앱 **더보기 → 설정 → PC ↔ 폰 동기화** → 토큰 붙여넣기 → **연결**
   → "연결했어요. 다른 기기의 기록을 합쳤습니다". PC의 학습 계획·풀이 기록·단어 카드가 들어옵니다.

### 언제 맞춰지나요?
| 상황 | 동작 |
|---|---|
| 앱을 열 때 / 다른 앱 쓰다 돌아올 때 | 자동으로 받기 |
| 앱을 벗어날 때(홈 버튼, 창 최소화) | 자동으로 올리기 |
| 공부하는 중 | 마지막 변경 20초 뒤, 그리고 5분마다 |
| 바로 맞추고 싶을 때 | 설정 → **지금 동기화** |

두 기기에서 같은 날 공부해도 기록이 **합쳐집니다**. 풀이 기록·학습량은 모두 더해지고, 체크와 계획 수정은 나중에 한 것이 남습니다. 인터넷이 없을 때 공부한 것도 연결되면 올라갑니다.

### 문제 해결
| 표시 | 원인과 조치 |
|---|---|
| 토큰이 올바르지 않거나 만료되었습니다 (401) | 토큰을 다시 복사하거나 새로 만듭니다 |
| 권한이 없거나 요청 한도를 넘었습니다 (403) | 토큰에 **Gists: Read and write** 권한이 있는지 확인합니다 |
| 네트워크 오류 (PC) | 회사망에서 `api.github.com`이 막혀 있을 수 있습니다. 앱은 Windows 프록시 설정을 따릅니다. 집이나 핫스팟에서 시도하거나 IT 정책을 확인하세요 |
| "모든 기록 초기화"를 했더니 다른 기기도 초기화됨 | 정상 동작입니다(확인 창에 안내됨). 한 기기만 정리하려면 먼저 **연결 해제**를 하세요 |
| 폰을 잃어버림 | GitHub → Settings → Developer settings에서 `jlpt-sync` 토큰을 **Revoke**하고 새 토큰을 만드세요 |

## 부록: GitHub 없이 쓰기
- **호스팅:** PC에서 `npm install && npm run build:web`을 실행한 뒤 `www` 폴더를 Netlify Drop(https://app.netlify.com/drop)에 끌어다 놓으면 주소가 생깁니다. 무료 계정이 필요합니다. 설치 방법은 2번과 같습니다.
- **동기화:** 설정 → **내보내기**로 백업 파일을 공유(카톡·드라이브)합니다. 다른 기기의 설정 → **가져와서 합치기**를 쓰면 덮어쓰지 않고 합쳐집니다.
